# 調査した遊び方と、このアプリのルール

調査日：2026-09-27。ルールには地域差があります。以下は調査を参考にしたアプリ独自の採用仕様です。連盟公認・大会準拠を意味しません。ゲームを選んだ次の画面で設定し、通信対戦ではホストの設定を全員に配ります。遊び方もアプリ内に同梱しているため、乗船後にリンクを開く必要はありません。

## 2人用の対局時計

今回さらに追加した、かんたん麻雀・会話・短時間ゲーム9種類は [CASUAL_GAMES.md](CASUAL_GAMES.md) を参照してください。現在は全29ゲームです。

既存5ゲームすべてで、無制限、1・3・5・10・15・30・60分を選べます。「10分切れ負け」「5分＋1手3秒」「将棋10分＋30秒読み」のボタンもあります。

- 加算：合法手を確定するたびに2・3・5・10・30秒を加えます。
- 秒読み：本来の持ち時間が0になった後は1手10・20・30・60秒。持ち時間を使い切った手も、その超過部分から秒読みを消費します。次の自分の手番では秒読みが回復します。複数期間制ではありません。
- 加算と秒読みはどちらか1つ。時間切れは負け。大会特有の「相手の戦力ではメイトできない場合の時間切れ引き分け」等の審判裁定は行いません。
- ローカルでは「時計を開始して対局」で開始。通信では接続完了から開始。手を指すと自動交代し、オセロで相手がパスして同じ人の手番になる場合も、1手として加算します。
- 通信の時計はホスト基準。ネットワーク遅延の補償はなく、ホストに届くまでの時間を含みます。切断を検出すると停止し、再接続時に合わせます。画面ロックから切断検出までの時間は消費される場合があります。
- 時計付きの途中対局は保存せず、画面終了・再読み込みで失われます。時計なしの既存ローカル盤面保存とは別扱いです。

参考：[FIDEの時間区分](https://handbook.fide.com/chapter/B02RBRegulations2024)、[日本将棋連盟の15分・30秒読み採用例](https://www.shogi.or.jp/files/2017.03.13.113906.pdf)。本アプリは友人同士で遊ぶための設定を提供し、棋戦の正式な時間区分を表示しません。

### 盤・タイル・ダイスをさらに追加

| ゲーム             | 人数 | 選択できること                                              |
| ------------------ | ---- | ----------------------------------------------------------- |
| マンカラ（カラハ） | 2    | 各穴の初期石数3・4・6、捕獲ON/OFF、ゴールで連続手番ON/OFF   |
| 石取り（ニム）     | 2〜7 | 3・4・5山、1回の上限なし・1・2・3個、最後を取ると勝ち／負け |
| ドミノ             | 2〜7 | 山札を引くドロー式／引かないブロック式                      |
| ヨット・ダイス     | 2〜7 | 1手番1・2・3ロール、上段63点で35点ボーナスON/OFF            |

マンカラはカラハ系のルールです。自分の6穴から1つを選び、反時計回りにまいて相手のゴールを飛ばします。最後が自分の空き穴で、向かいに石があると捕獲。片側が空になったら残りはその側のゴールへ集めます。初手後の先後交換（パイルール）はありません。参考：[Yellow Mountain Importsの遊び方](https://www.ymimports.com/pages/how-to-play-mancala)。ルール差のある終局時の残り石や空き穴捕獲は、このアプリの上記仕様に固定しました。

ニムは1つの山から指定数を取る形式です。多人数でも同じ順番で行い、最後を取った人が勝ち。逆ルールではその人だけが負けて残り全員が勝ちます。参考：[Cambridge NRICHのNim-Like Games](https://nrich.maths.org/games/nim-games)。2人用の数学的戦略が、そのまま多人数でも通用するとは限りません。

ドミノは0〜6の28枚で、2人には7枚、3〜4人には5枚、5〜7人には4枚を配ります。出せるタイルがあるときはパスや山札取りは不可。初手は席1から任意のタイルを置きます。残り0枚か全員が詰まると終了。後者は残った点の最小者が勝ち、同点勝ちもあります。チーム戦や複数ラウンドの得点戦は採用していません。参考：[PagatのBlock Dominoes](https://www.pagat.com/domino/line/block.html)。5〜7人の配り方はこのアプリの拡張です。

ヨットはハウスルールの12枠制。上段1〜6は該当する出目の合計、チョイスは全出目の合計、フォーダイスは4個以上同じなら全合計、フルハウスは3個＋2個なら全合計です。同じ5個はフルハウスに含めません。小ストレートは連続4種類で15点、大ストレートは連続5種類で30点、ヨットは同じ5個で50点。役が成立しない枠へ0点を記録することもでき、再使用不可。全員が12枠を埋めて終了します。追加ヨットボーナスやジョーカー代用はありません。参考：[Math is FunのYacht](https://www.mathsisfun.com/games/yacht-dice-game.html)、[Walnut StudioloのYacht/Yatzy比較](https://walnutstudiolo.com/blogs/blog/how-to-play-dice-yacht-yatzy-game-rules-of-play)。名称が似たゲームでも得点が違うため、採点はアプリに表示した値を優先します。

## 大富豪の細部

53枚を全員に配り、♦3を持つ人から始めます。通常は3が最弱、2が最強、単体ジョーカーはさらに強く、革命中もジョーカーは最強です。1枚・同数組・階段の形と枚数をそろえます。一度パスすると、その場が流れるまで出せません。最後に出した人以外の活動中の全員がパスしたら、その人（上がっていれば次の人）から再開します。

選択ルールの相互作用は以下に固定しています。

- 革命：同数4枚以上、階段5枚以上。ジョーカーは同数組の代用になります。
- 階段：同じマークで3枚以上。数字の順は3〜K〜A〜2。A・2・3はつながりません。ジョーカーの階段代用は採用しません。
- 8切り：実物の8を含む手で場を流します。階段にも適用します。
- 11バック：実物のJを含む手で、その場の強弱を反転します。階段にも適用し、再度Jが出れば戻ります。革命と11バックが両方有効なら反転が相殺されます。場が流れると11バックだけ解除します。
- 縛り：ジョーカーを含まない同じマーク構成が2回続くと固定。ジョーカー入りでは新たな縛りは発生しません。縛り中のジョーカー単体は不可。同数組内でも実物のマーク構成が一致する必要があります。
- スペ3返し：単体ジョーカーに単体♠3を返して場を流します。縛りより優先します。
- 禁止札上がり：出す前の強弱を基準に、最強数字・ジョーカー・8切り有効時の実物8を含む最後の手を反則負けにします。階段にも適用。操作は拒否せず、その人を除外して最下位側から順位を確定するため、出せる手がなくなって進行が止まりません。
- 全順位を確定して終了。反則負けが複数なら、先に反則した人ほど下位です。再戦時は階級を引き継がず新しく配ります。都落ち・階級による札交換・5飛び・7渡し・10捨て等は今回採用していません。

調査元：[日本大富豪連盟の公式ルールブック](https://daifugojapan.com/rule-book)、[トランプスタジアムのローカルルール例](https://playingcards.jp/game_rules/modal/daifugo_rules_modal.html)。公式と地域ルールではデッキ枚数や階段の扱いなどが異なるため、上記のアプリ仕様を優先します。音声の「エジバック」は11バック（Jバック）と解釈しました。

## 人数拡張・デジタル化に伴う判断

- ダウト：先着で叫ぶ形式では通信遅延に影響されるので、出した人の次の席から1人ずつ判断します。最初のダウトで解決。誰も疑わなければ次の宣言へ。手札を出し切っても確認が終わるまでは勝利になりません。解決後は出した人の次から再開します。
- 七並べ：AとKは連結せず、ジョーカーなし。脱落者の公開札の隣にもつなげます。
- ゴーフィッシュ：2〜3人は7枚、4〜7人は5枚を配ります。手札0枚で自分の番になったら山札から1枚補充。山札がなければ手札0枚の人は手番を飛ばします。最多得点が複数なら同点勝ちです。
- クレイジーエイト：出せる札があるときも引けますが、出せる札があればパスは不可。山札がなくなったら捨て札の最上段以外を混ぜます。全員が出せずパスしたら手札の罰点が少ない人の勝ち（8は50、絵札10、Aは1）。
- ハーツ：交換なし。人数で割り切れるまで低い♣・♦（♣2、♦2、♣3、♦3、♣4、♦4の順）を除きます。最小の♣で開始し、同じマークを持っていれば必ず出します。最初の巡回の失点札を避ける義務と、♥が捨てられる前の♥リード制限があります（他に出せない場合を除く）。♥1点・♠Q13点で合計26点。全取得の反転はラウンド終了時に処理します。
- 神経衰弱：同じ数字を2枚ずつに絞り、スマホで見やすい16〜26枚。2枚の結果は「確認して次へ」まで保持します。裏のカードの内容は参加側に送りません。
- ドット＆ボックスとダイス：基本の操作を人数分の順番で繰り返す拡張です。前者は同点勝ちあり、後者は先に目標へ到達した人が勝ちです。
- 全追加ゲームは10,000操作で引き分けにする安全上限を設けています。無限に引き延ばす遊び方や、全員がダウトし続ける循環に備えたもので、一般ルールの一部ではありません。
