# Offline Board Games

[English](README.md) | **日本語**

**公開アプリ: <https://offline-board-games.vercel.app/>** — スマートフォンで開いてホーム画面に追加し、「オフライン利用可能」の表示が出るまで待ってください。

フェリーの上や旅行先など、インターネットのない場所で友人と遊ぶための、ボードゲーム・カードゲーム25種を収めたオフラインファーストのPWA（プログレッシブWebアプリ）です。アカウント、広告、アクセス解析、バックエンドのデータベースはありません。初回の読み込み後は、完全にオフラインで動きます。UIは日本語です。

> 1台の端末を回して遊ぶ場合（2〜7人）は、ネットワークは不要です。複数の端末で遊ぶには、同じLANやテザリングで端末同士が通信できる必要があります。動作は端末・OS・テザリングの設定によって変わるので、事前に実際の端末で試してください。

## 主な機能

- 25ゲーム: 2人用の定番5種と、2〜7人で遊べる20種。1台を共有しても、各自のスマホでも遊べる
- 2人用ゲームの対局時計（持ち時間、加算、秒読み）と、細かく設定できるハウスルール
- WebRTC DataChannelによる、サーバーなしのP2P対戦。接続は圧縮したQRコードかテキストを交換して行い、シグナリングサーバーもSTUN/TURNも使わない
- 手札などの非公開情報は持ち主にだけ送信。同期は状態の差分のみ。再接続とホスト主導の再同期、全員の合意による再戦
- アプリ本体と全ゲームエンジンを事前キャッシュし、キャッシュの中身を確かめる「オフライン準備完了」チェック
- 合法手のハイライト、成りの選択、投了、再戦、盤面の反転、対局履歴、テーマ、効果音
- 幅320 pxまで対応するレスポンシブ表示、ダークモード、キーボード操作

## ゲーム

2人用の定番: オセロ、チェス、将棋、五目並べ、四目並べ。2〜7人で遊べる追加ゲームには、マンカラ、ニム、ドミノ、ヨット、大富豪、七並べ、ババ抜き、ゴーフィッシュ、神経衰弱、ハーツ、ダウト、ドット＆ボックス、ヒット＆ブロー、ワードウルフ、オリジナルのパーティーゲーム2種（人生すごろくと交易ゲーム）があります。正確な一覧、ルール、選択項目、参考にした資料は [docs/RULES.md](docs/RULES.md)（日本語）を参照してください。

*「オセロ」「Connect Four」はそれぞれの権利者の商標です。本アプリは伝統的なゲームのルールを非公式・非商用で実装したものです。*

## 技術スタック

React、TypeScript（strict）、Vite、vite-plugin-pwa、Workbox、Service Worker、WebRTC RTCDataChannel、Vitest、ESLint、Playwright。ライブラリ: `chess.js`、`qrcode`、`jsQR`、`fflate`。実行時にCDN、Webフォント、アクセス解析、外部APIには一切依存していません。

## 開発

Node.js 22.12以降が必要です。

```bash
npm install
npm run dev        # 開発サーバー（Service Workerは無効）
npm run build      # dist/ に本番ビルド
npm run preview    # ビルドを http://localhost:4173/ で配信
npm run typecheck && npm run lint && npm test
npx playwright install chromium && npm run test:e2e
```

カメラとService WorkerはHTTPSかlocalhostでのみ動きます。PWAとしての動作は本番ビルドで確認してください。

## テスト

- Vitest: ゲームのルール、状態のシリアライズ、不正な入力、QRの圧縮と分割、再同期、再接続、再戦。
- Playwright: 本番ビルド、マニフェスト、Service Worker、全ゲームのオフライン再読み込み、外部へのHTTPリクエストがないこと、幅320 pxのレイアウト、独立した2〜7個のブラウザコンテキスト間での実際のWebRTC接続。

ブラウザの自動テストが通っても、実際のiPhone/Androidのテザリングで接続できる保証にはなりません。[docs/VERIFICATION.md](docs/VERIFICATION.md) と [ARCHITECTURE.md](ARCHITECTURE.md) を参照してください。

## 制限事項

- テザリング、Wi-Fi、端末の組み合わせは実機で試す必要があります。クライアント分離、mDNS/UDPの遮断、OSのローカルネットワーク権限によって、端末同士が接続できない場合があります。
- 状態ダイジェストは同期のずれを検出するためのもので、署名ではありません。非公開の状態はすべてホストが持つため、信頼できる相手と遊んでください。
- コンピューター対戦、インターネット越しの対戦、観戦機能はありません。

ルールの補足、接続方法、デプロイ手順などを含む詳しい日本語ドキュメントは [docs/DETAILS.ja.md](docs/DETAILS.ja.md) にあります。
